# Result Management System

An Express, EJS and MongoDB application for student results and teacher administration.

Run `npm ci` (or `npm install` if no lockfile is available), copy `.env.example` to `.env` and set `MONGODB_URI` and a long random `SESSION_SECRET`. Start with `npm start`. The port defaults to 3000. Local environment files are excluded from Git.

This application requires a Node.js server and MongoDB. GitHub Pages cannot host its authentication, database or server-rendered routes. Review authentication and validation before using real student data.
